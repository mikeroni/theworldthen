# Security

Security fixes are made in the current version on `main` and the current site at https://theworldthen.com. Older releases are not maintained separately. If you use a downloaded offline copy, check whether a newer release is available.

Please report suspected vulnerabilities through [GitHub's private reporting form](https://github.com/mikeroni/theworldthen/security/advisories/new), or email mikemanning1223@gmail.com. Do not post sensitive information or exploit details in a public issue.

Include the affected page or release, steps to reproduce, and the impact you expect. Avoid accessing other people's data or disrupting the site.

This is a personal project maintained in spare time. Reports are reviewed on a best-effort basis; there is no guaranteed response time or paid bounty program.

Historical corrections and ordinary site bugs belong in GitHub Issues, not the private security reporting channel.
